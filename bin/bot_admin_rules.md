**Rules for Using the Brick Rigs Moderation Bot**  

*1.*  
Do not send NSFW content to the server via the bot or game chat. This includes foul language. Doing so will result in bot privileges being revoked and a warning issued in Discord, depending on the severity of the violation.  

*2.*  
Be respectful at all times, even when someone is breaking the rules. Do not argue with other bot admins in the game server—take it to https://discord.com/channels/1247723267029074002/1247894755380297791.  

*3.*  
Only change server settings like weather and time when a player requests it. Do not change them just to be annoying. This means that even if *you* want it to be stormy and midnight, you cannot change it unless a majority of the server agrees.  

*4.*  
Do not ban other bot admins unless it is an emergency. If you have an issue with another bot admin, ping Rank II.  

*5.*  
Use warnings or 10-minute bans for first offenses unless the issue is severe. Spawning OP vehicles, spawn-killing, and team-killing are **not** considered serious. Attempted server crashing, slurs, and sexual content **are** serious issues. If a player repeatedly breaks the rules, permaban them.  

*6.*  
The "no OP vehicles" rule exists to provide a reason to ban players for something not explicitly stated in the rules. When banning someone for this, specify in what way their vehicle is OP and warn them beforehand—unless it's an obvious troll vehicle with 3,000 AP.
